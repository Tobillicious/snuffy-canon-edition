## Open pātai (archive holding, G3)
Data processing: recovery needs only the decoded payload (≤ I₀ + the particular's transcript
b₀ + bN bits), not raw patch data. At holding rate γ per bit-step, payload holding costs O(γ t²),
inside O(t^{d_G}) for d_G ≥ 2. A raw-patch archive costs ~γ t^{d_G+1} and breaks the bound, so the
architecture must hold the payload. For d_G = 1, t² > t: needs a time-decreasing refresh rate
(self-correcting memory) or a bounded transcript. Ties to the open holding-power item.
